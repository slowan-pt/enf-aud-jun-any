======================================================================
REGRA MÁXIMA: EXECUÇÃO EM DUAS ETAPAS
======================================================================

Este projeto deve ser desenvolvido OBRIGATORIAMENTE em duas etapas independentes e sequenciais:

ETAPA 1 — VISUAL / FRONTEND / ESQUELETO COMPLETO
ETAPA 2 — BACKEND / CMS REAL / BANCO / AUTENTICAÇÃO / PERSISTÊNCIA / INFRAESTRUTURA

A ETAPA 2 FICA EXPRESSAMENTE BLOQUEADA ATÉ APROVAÇÃO HUMANA DA ETAPA 1.

Execute AGORA SOMENTE A ETAPA 1.

Você só poderá iniciar a ETAPA 2 depois de o proprietário escrever de forma inequívoca algo equivalente a:

- "Etapa 1 aprovada."
- "Aprovado, pode iniciar a etapa 2."
- "Pode fazer o backend."
- "Pode seguir para a etapa 2."

Até essa autorização, é proibido:
- criar ou conectar Cloudflare D1;
- criar banco de dados real;
- criar APIs reais;
- implementar persistência;
- implementar autenticação real;
- implementar sessões reais;
- criar CMS funcional com gravação;
- processar formulários no servidor;
- criar upload real para R2;
- criar Turnstile funcional;
- armazenar contatos;
- configurar backend de produção;
- executar migrations;
- publicar alterações de backend;
- adiantar silenciosamente qualquer parte da ETAPA 2.

A arquitetura da ETAPA 1 deve, entretanto, ser preparada para que o backend seja conectado depois sem reconstruir o visual aprovado.
